# Cost model

Ferrocat now separates pre-feasibility cost classes instead of applying one flat rate to every kilometre:

- active existing railway adaptation;
- disused railway rehabilitation;
- new surface railway;
- tunnel;
- viaduct;
- cut/fill allowance (Python domain model).

Defaults are scenario parameters, not quotes or construction budgets. Tunnel cost is intentionally much higher than surface railway so mountain crossings have the expected economic effect. Values must be recalibrated against dated project references before using Ferrocat for comparative policy analysis.
